# 오류 코드 카탈로그

자동 검사 스크립트와 에이전트 판단 항목의 코드·심각도 기준. 보고서의 `코드`/`심각도` 열은 이 표를 따른다.

## 심각도 기준

| 심각도 | 기준 |
|---|---|
| 높음 | 금액에 직접 영향(산술·합산·요율 계산 오류, 기초금액 불일치), 도면 누락 등 계약·정산 분쟁 소지 |
| 중간 | 금액 영향 가능성이 있으나 의도일 수도 있는 것(중복·단위·단가 편차, 개정번호 상이, 누락 공종 의심) |
| 낮음 | 표기·형식 문제, 오탐 가능성이 큰 단서(축척 표기, 규격 토큰 차이 등) |

조정 규칙
- 저신뢰 추출 행(`low_confidence`)·스캔 페이지에서 나온 지적은 원본(이미지)으로 확인 전까지 한 단계 낮추거나 "확인 필요"로 표시한다.
- 같은 원인으로 연쇄된 지적(항목 산술 오류 → 소계·합계 B01, 경비계 오류 → 이윤 C01 등)은 원인 1건을 대표로 남기고 나머지는 근거에 "연쇄"로 묶는다.
- 차액이 총공사비 대비 극히 작아도(예: 단수 처리 1원) 심각도는 낮추되 삭제하지 않는다. 단, 스크립트가 이미 1/10/100/1000원 절사·반올림은 허용한다.

## 내역서 (check_boq.py)

| 코드 | 이름 | 심각도 | 판정 방법 | 흔한 오탐 |
|---|---|---|---|---|
| B01 | 산술 오류 | 높음 | 항목: 수량×단가 ≠ 금액 (재료비·노무비·경비·합계 각각). 모든 행: 재료비+노무비+경비 ≠ 합계 (단가·금액) | 단가가 소수점 이하 절사 표시된 경우, PDF 추출 열 밀림 |
| B02 | 소계·합계 불일치 | 높음 | 소계/합계 행 금액 ≠ 하위 항목 합. 소계 범위는 공종 계층(번호 체계)·소계 명칭으로 추정하고, "직전 소계 이후"도 후보로 비교 | 집계표·별도 시트 공종, 소계 범위 추정 실패(근거에 표시) |
| B03 | 단위 불일치 | 중간 | 같은 품명·규격(norm_key)인데 정규화 단위가 다름 (예: TON vs kg) | 구간별로 의도적으로 다른 단위 사용 |
| B04 | 중복 항목 | 중간 | 같은 공종 경로 + 품명·규격 + 수량 반복 | 층별·구간별 동일 수량 반복이 의도된 경우 |
| B05 | 단가 편차 | 중간 | 같은 품명·규격·단위인데 단가 차이 > `--outlier-pct`(기본 5%) | 할증·소운반 포함 여부 차이, 공종별 다른 일위대가 |
| B06 | 누락 공종 의심 | 중간 | **에이전트 판단** (아래 체크리스트) | 별도 발주·관급·타 공정 포함 |

### B06 누락 공종 체크리스트 (에이전트가 내역서 공종 목록과 대조)

자동 검사 대상이 아니다. 공종 그룹(`type: group`)과 항목명을 훑어 아래 항목이 보이지 않으면 "누락 의심"으로 보고하되, 별도 발주·관급·타 내역서 포함 가능성을 근거에 적는다.

- 가설공사: 공통가설(가설사무실·창고·울타리·가설전기·용수), 직접가설(규준틀·먹매김·비계·안전시설)
- 폐기물 처리: 건설폐기물 운반·처리비(성상별), 잔토 처리
- 안전관리: 안전시설(난간·추락방지망·낙하물방지망), 산업안전보건관리비(원가계산서)
- 품질관리: 품질시험비, 시험 시료 채취
- 운반: 자재 소운반, 장비 운반(왕복), 잔토 운반
- 할증: 철근·형강·합판 등 할증량 반영(수량에 포함됐는지)
- 기타 자주 빠지는 것: 동절기 보양, 양생, 줄눈·코킹, 청소·준공 정리, 환경관리(살수·세륜), 시험·검사비, 인허가 관련 비용, 터파기에 따른 되메우기·잔토처리 짝

## 원가계산서 (check_cost_summary.py)

| 코드 | 이름 | 심각도 | 판정 방법 |
|---|---|---|---|
| C01 | 요율 계산 불일치 | 높음 | 산정기준 × 요율 ≠ 기재 금액(절사 허용). 요율은 `--rates` 우선, 없으면 문서 표기 %. 문서 표기 요율과 rates.json 요율이 다르면 별도 C01(중간) |
| C02 | 기초금액 불일치 | 높음 | 직접재료비·직접노무비·기계경비 ≠ 내역서 재료비·노무비·경비 합 (`--boq` 지정 시) |
| C03 | 원가계산서 합산 불일치 | 높음 | 재료비계·노무비계·경비계 ≠ 블록 내 비목 합, 순공사원가 ≠ 재+노+경, 총원가/공급가액/총공사비 ≠ 직전 단계 + 사이 비목 |

- 요율 정보가 없으면 지적하지 않고 경고에 "역산 요율"만 남긴다 → 에이전트가 사용자에게 적용 요율을 확인.
- 산정기준(BASES)은 관행 기준이다. 발주처 기준이 다르면 결과를 해석할 때 반영한다(`references/rates-guide.md`).

## 도면 (check_drawings.py)

| 코드 | 이름 | 심각도 | 판정 방법 |
|---|---|---|---|
| D01 | 도면번호/목록 불일치 | 높음(목록에 있으나 도면 없음) / 중간(목록에 없는 도면, 도면명 상이, 스캔 페이지 존재 시) | 도면목록 ↔ 표제란 도면번호·도면명 대조 |
| D02 | 축척 | 낮음 | 표제란 축척 누락, 목록과 축척 상이 |
| D03 | 개정 | 중간 | 표제란 개정번호 ≠ 도면목록 개정번호 |
| D04 | 중복 도면번호 | 중간 | 같은 도면번호가 여러 페이지에 존재 |

## 교차 확인 (cross_check.py)

| 코드 | 이름 | 심각도 | 판정 방법 |
|---|---|---|---|
| X01 | 도면-내역 규격 불일치 | 중간~낮음 | 도면 규격 토큰(fck, D13, SD400, H-형강, THK, Φ 등)과 내역서 품명·규격 토큰을 비교해 한쪽에만 있는 것을 단서로 제시. 오류 확정이 아니므로 에이전트가 주요 부재 위주로 걸러낸다 |
