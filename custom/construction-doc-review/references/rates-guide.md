# 원가계산 요율 가이드

`check_cost_summary.py` 가 요율을 재계산할 때 쓰는 산정기준과 `rates.json` 형식.

## 주의

- **요율은 매년(또는 수시로) 바뀐다.** 보험료율, 간접노무비율, 일반관리비·이윤 상한, 산업안전보건관리비 요율 등은
  해당 연도 고시·발주처 지침·공사 규모·공종에 따라 다르다.
- 이 문서와 스크립트에는 **특정 연도의 요율을 사실로 넣지 않는다.** 에이전트는 요율을 추측하지 말고
  1) 원가계산서에 표기된 % 를 쓰거나, 2) 사용자에게 적용 기준(발주처·연도)을 묻고 `rates.json` 을 만든다.
- 문서 표기 요율로 검사하면 "표기대로 계산했는가"만 확인된다. 요율 자체의 적정성은 사용자/발주처 확인 사항으로 보고서 "검토 한계"에 적는다.

## 산정기준 (스크립트 `BASES`, 관행 기준)

| 비목 | 산식 | 비고 |
|---|---|---|
| 간접노무비 | 직접노무비 × r | |
| 산재보험료 | 노무비(직접+간접) × r | |
| 고용보험료 | 노무비(직접+간접) × r | |
| 국민건강보험료 | 직접노무비 × r | |
| 국민연금보험료 | 직접노무비 × r | |
| 노인장기요양보험료 | 국민건강보험료 × r | |
| 퇴직급여충당금 | 노무비 × r | 관행. 발주처 확인 |
| 산업안전보건관리비 | (재료비 + 직접노무비) × r | 관급자재·대상액 구간별 기초액 등은 반영하지 않음 |
| 환경보전비 | (재료비 + 직접노무비 + 기계경비) × r | 관행. 발주처 확인 |
| 기타경비 | (재료비 + 노무비) × r | 관행. 발주처 확인 |
| 일반관리비 | (재료비 + 노무비 + 경비) × r | 순공사원가 기준 |
| 이윤 | (노무비 + 경비 + 일반관리비) × r | 경비 중 일부 제외 규정이 있으면 차이 발생 |
| 부가가치세 | 공급가액 × 10% | 공급가액이 없으면 총원가 사용 |

- 노무비 = 노무비계(없으면 직접+간접), 재료비 = 재료비계(없으면 재료 블록 합), 경비 = 경비계(없으면 경비 블록 합).
- 금액 단수 처리: 계산값을 1·10·100·1000원 단위로 절사/반올림한 값 중 하나와 맞으면 일치로 본다.
- 문서에 소수 2자리 이상으로 표기된 요율(예: 3.545%)은 표시 반올림 범위 내 차이를 경고로만 남긴다.
- 발주처 기준이 위와 다르면(예: 산재보험료를 직접노무비 기준으로 계산) C01 이 오탐일 수 있다. 근거의 "역산 요율"로 판단한다.

## rates.json 형식

값은 **퍼센트 숫자**(3.5 = 3.5%)로 적는다. 모르는 요율은 넣지 않는다(넣지 않은 비목은 문서 표기 % 로 검사).

```json
{
  "note": "출처: (예) 발주처 OO 원가계산 지침 20XX년 / 사용자 제공",
  "rates_pct": {
    "간접노무비": <r>,
    "산재보험료": <r>,
    "고용보험료": <r>,
    "국민건강보험료": <r>,
    "노인장기요양보험료": <r>,
    "국민연금보험료": <r>,
    "퇴직급여충당금": <r>,
    "산업안전보건관리비": <r>,
    "환경보전비": <r>,
    "기타경비": <r>,
    "일반관리비": <r>,
    "이윤": <r>,
    "부가가치세": 10
  }
}
```

`<r>` 는 자리표시자이며 실제 값으로 바꿔야 한다(JSON 숫자). `note` 는 경고 목록에 출처로 표시된다.
